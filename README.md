## 上傳方式
1. 到 https://github.com/auccelis-cmd/capture-pad 上傳本包根目錄的 index.html、sw.js、manifest.webmanifest，取代同名檔案。
2. 等待 GitHub Pages 部署完成。電腦重新整理，iPhone 主畫面 App 完全關閉後重開，頁尾應顯示 v3.0。
3. 所有裝置都要更新後再操作。既有帳號與連接方式維持原設定；不需清除資料或執行 SQL。

本次未取得 GitHub 寫入權限，並未修改線上網站或任何真實案件。

## 已加入
- 柔和紙色與鼠尾草綠介面，手機底部導覽。
- 六款字體：源泉圓體（預設）、獅尾圓體、辰宇落雁體、jf open 粉圓、芫荽、清爽黑體。頁尾可切換，本裝置會記住選擇。
- 新案、新入境、重招、續聘、承接、外技、旅宿境內、旅宿境外與一般案件。先記案件名稱即可，之後再補分類與流程。
- 「目前等誰／等什麼」「下一步」「下次追蹤日」，可快選明天、三天後或自訂日期。
- 可連結其他案件，原案件仍各自獨立。
- 多個重要期限、最近期限摘要與提醒。延後追蹤不會延後辦件期限；手動期限完成後保留設定。
- 結案封存、搜尋封存案件、保留備註與追蹤紀錄，並可重新開啟。封存後不再出現在提醒與正在做。
- 承接含雙方、三方、期滿轉換、第五順位、第七順位。自轉自接列在三方合意。
- 第五／第七順位可設定登記日、人工確認名額、各批承接日期與人數；每批產生通報及聘僱／居留提醒。超過登記期間或名額時會阻止新增。
- 工業局函核發加六年。承接登記加60天，一般承接通報加2天、聘僱與居留加15天；期滿轉換最晚通報為期滿前一天，聘僱按實際通報日加15天。
- 重招／續聘填期滿日後顯示四個月前開始、兩個月前申請期限。
- 新入境與旅宿國外引進保留挑工、送簽、領簽、入境日期及入境後期限。沒有新增6／18／30個月體檢提醒。

## 使用上的範圍
- 流程項目是可選的辦件清單；不同種類的準備工作可以並行。預估審查工作日未當作法定期限。
- 外技與旅宿人員資格提供流程確認項目，尚未加入完整年資、薪資與雇主名額資格試算。請先以人工確認結果填寫名額與期限。
- 第五／第七順位提供週二傳真、週四09:00–11:00的作業提示，沒有站外推播。
- 新增的案件本資料沿用現有 progress_log JSONB，使用保留項目 id=casebook-meta-v1 儲存設定；不更動舊欄位，不需要資料庫結構更新。舊版App無法辨識封存設定，所以請更新所有裝置。
- 任何手動期限都可完成／收起；自動產生的承接批次期限要完成該批次，結案後則全部停止提醒。
- 改變案件分類會保留既有子任務，不會自行刪除或重新套用。
- 字體從各開源專案 CDN／Google Fonts 載入；首次切換需要網路，載入時先顯示替代字體。
